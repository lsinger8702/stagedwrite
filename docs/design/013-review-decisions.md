基线：b70ee4c，2026-09-13。独立复核结合第三至七轮意见、当前源码和临时实验。
这份记录区分已证明的问题、既定行为和后续能力；重复出现不自动提高优先级。

|---|---|---|

## 过期补丁的处置

第七轮补丁不能直接应用到基线；拒绝原样合入，不代表拒绝后续正确实现。
H3 补丁遗漏 reused、失败 checkpoint 和内部失败来源；其“解析失败即零效果”的结论不能推广到所有损坏状态。
F6 补丁引用已经移除的 checks Map，未处理 SQLite epoch、check/plan 原子绑定和跨实例竞争。
如果父回执真的缺失，恢复校验也可能拒绝；不保证内部不变式错误总能靠重启解决。

## 下一步验收

1. 会话清理后仍能恢复每条未完成 run，审计事件保留原 owner 标识，失败事务不改变归属。
2. 保留政策与 README 一致；不把“政策已定”写成“通用 GC 已实现”。
3. 已有对象接入先落实目标身份、来源证据与 unknown 边界；未落地前继续拒绝闭合 run 的直接派生。
4. 外部试用前完成容量和预检基准、兼容入口决策，记录实际运行环境与结果。
