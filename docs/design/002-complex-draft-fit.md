# 002：复杂对象图的扩展边界

本文说明通用项目、任务与共享文档场景的能力边界。具体已实现行为以对应里程碑文档和测试为准。

## 数据模型

| 场景 | 当前能力 | 后续边界 |
|---|---|---|
| 项目包含任务、多个项目引用同一文档 | 显式节点与关系；节点身份不可复用 | 根节点、关系基数和额外拓扑约束由规则表达 |
| 标量字段与本地 Schema 引用 | 支持字段校验、$defs/$ref、定义摘要 | 不支持任意嵌套对象和数组编辑 |
| 公共字段与扩展字段同名 | 单一字段空间 | 命名空间需要独立坐标与校验契约 |
| 显式赋值、清空与未声明 | value/clear/缺失分别表达 | 推导值不能静默替换作者声明 |
| 预览与编辑一致 | 共用纯 evaluateGraphEdit | 快捷操作应展开为同一套核心 OP |
| 共享文档替换与孤儿回收 | 基础节点/边操作可表达 | 不自动级联，回收时机需独立定义 |
| 删除后的身份 | 墓碑保留，普通新增不可复用 | 导入、恢复与归档需另定身份策略 |
| 已有远端对象 | 尚无导入入口 | 需要可信来源、目标身份与结果映射 |

## 编辑与恢复

1. evaluateGraphEdit 只返回候选图和变化事实；提交层负责版本 CAS 与检查失效。
2. OP 严格按数组顺序执行，不擅自改为拓扑顺序；整批最终结构必须有效。
3. 缺少发布必填字段允许保存，已提供值必须符合结构约束。
4. reset 取消字段声明；恢复指定历史基线是不同操作，不能混用。
5. 发布后保留封存。零效果失败可 revise；符合创建映射的部分成功可 continueFrom。
6. 续跑的已成功节点保持不变，复用回执保留来源；不能从一个远端 ID 推导完整远端状态。

## 规则与执行

Definition 表达结构与关系，Runtime binding 表达规则、计划、执行及恢复能力。
普通检查与预览不允许隐藏上传文件等外部写入，外部副作用必须进入执行步骤与事件。
检查绑定结构、规则和版本；执行额外绑定固定计划及目标身份。
Schema 冻结不等于远端状态冻结，检查通过也不是对外部服务成功的保证。

## 后续扩展

保持核心流程可独立验收。嵌套数据、命名空间、基线恢复、已有对象导入与多操作节点分别设计。
SQLite 草稿/检查存储已实现；执行事实持久化与跨进程恢复继续按路线图推进。
