## 每个任务怎么推进

1. 从 design/TEMPLATE.md 建一份短设计。
2. 写清输入输出、错误行为、验收案例，不追求大量类图。
3. 实现一个完整行为，同时写针对其失败风险的测试。
4. 跑相关测试和示例；更新 roadmap 和 README。
5. 提交一份可运行版本。需要外部讨论时，再开小 PR。

完成标准：代码实现、验收通过、可运行示例、状态文档四项齐全。仅有设计或空接口不能打勾。
